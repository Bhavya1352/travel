# Voyara

Voyara is an AI-powered travel planning application that helps users discover destinations, create itineraries, and organize trips in one place.

## Features

* AI-powered trip planning
* Destination discovery
* Create and manage itineraries
* Save multiple trips
* Responsive design

## Tech Stack

* React
* Vite
* Tailwind CSS
* React Router
* TanStack Query
* Framer Motion

## Run Locally

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
